# study-web · 学习资料库

> 跑在自己电脑上的学习资料库：本地资料目录**只读**收录、全文搜索、AI 问答 / 摘要 / 出题 / 看图识字、
> 33 个数理化模型动画，自带管理端、离线单文件分享版和 PWA。
> **程序只读你的资料，一个字节都不改**；仓库里只有代码，不含任何资料、账号或密钥。

**在线体验**（就是仓库里 `docs/index.html` 那份**离线单文件版**：只有界面、33 个模型动画和工具，
**不含任何资料 / 账号 / 笔记 / 密钥**；进去要先输分享码 —— 门禁而已，代码本身是公开的）：

- GitHub Pages：<https://yunyunlyk.github.io/study-web/>
- 自定义域名：<https://study-web.com/>（域名解析配置中）

一个跑在你自己电脑上的学习资料网站：自动收录你指定的资料目录（默认值在 `core/config.py`，
也可以在管理端再加最多 12 个只读目录）里的全部资料，支持网页上传、全文搜索、AI 识别扫描件、
AI 问答和出练习题，还能把选中的资料导出成可以直接发给同学的文件；资料里自带的网页/动画文件
可以直接在站内运行，站内还内置了 33 个数理化模型动画（10 数学 / 15 物理 / 8 化学，
全部本地绘制、断网也能看），可以让 AI 现场生成新的模型动画，可以在网上按主题收集知识点，
并且有独立的**管理端**来管账号、查违规、换 AI 模型、挪数据目录。

**技术栈**：Python 3.13 + Flask 3 + waitress + SQLite（WAL + FTS5 trigram 全文索引）为后端；
前端是原生 HTML / CSS / JavaScript，**没有任何构建步骤**（改完刷新浏览器即生效）；
可选依赖 `cryptography`（局域网自签 HTTPS）与 `qrcode`（隧道二维码）。
自带 10 个测试脚本（单元、接口、无头浏览器端到端）。

有三个页面要分清楚：

| 页面 | 地址 | 谁能进 |
| --- | --- | --- |
| 用户端 | `http://127.0.0.1:8787/` | 所有注册账号 |
| 管理端 | `http://127.0.0.1:8787/admin` | 只有管理员 |
| 离线分享版 | 导出的单个 `.html` 文件 | 拿到文件的所有人（不用账号） |

**先用三句话看懂「给谁用」：**

- **你自己（管理员）**：资料放在这台电脑上，只有你能看到；AI 用管理端里配好的模型。
- **普通账号（别人）**：他用邀请码注册，他自己的资料只存在**他自己的浏览器**里，不占你的硬盘、不花你的钱；
  AI 要填他自己的密钥，或者你打开「允许局域网共用我的 AI」借他用。
- **没有账号的人**：你发一个导出的单文件 `.html` 给他；或者用管理端生成「公网静态版」，
  配一个分享码，谁拿到文件谁就能打开（里面**没有任何你的资料**）。

## 一、怎么启动

1. 双击 `启动.bat`
2. 浏览器会自动打开 `http://127.0.0.1:8787`
3. 第一次进入先注册一个账号（**第一个注册的账号是管理员**，也就是你自己）；
   以后别人想注册需要**邀请码**，见「十七、谁能用这个网站」
4. 用完双击 `停止.bat`

手机 / 平板想访问：连上和电脑同一个 Wi-Fi，打开启动时那个黑色窗口里显示的网址。
如果打不开，多半是 Windows 防火墙拦住了，见下面「防火墙」。

## 二、资料放在哪

| 位置 | 内容 | 谁能看到 |
| --- | --- | --- |
| `D:\学习资料`（+ 你在管理端另加的只读资料目录） | 你原有的资料，**程序只读，绝不修改** | 只有管理员 |
| `D:\学习网页\data\uploads\分类\` | **管理员（你）**从网页上传的资料、AI 生成的模型动画 | 默认只有上传者本人 |
| 访客自己的浏览器 | **其他账号**上传的资料（浏览器自带的小仓库） | 只有他自己，连你也看不到，**不占你的硬盘** |

**默认全部私有。** 别人注册账号登录进来，看不到你文件夹里的任何东西；
他自己上传的东西也不会跑到你电脑上（程序会直接拒绝普通账号往服务器写文件）。
想让某个资料被其他账号看到，进资料详情页点「共享给其他账号」。
要把资料发给别人（他们不用注册），用下面的导出 / 分享功能。

## 三、AI 功能

AI 分两种用法：**管理员（你）**用管理端里配好的模型，默认指向本机的模型代理
（`127.0.0.1:15721`，不用密钥、不额外花钱）；**普通账号**用他自己在「我的 → AI 接入」里填的密钥
（浏览器直接连服务商，不经过你的服务器，也不花你的钱）。你也可以在管理端打开
「允许局域网共用我的 AI」，让没密钥的人借用你的额度（默认关闭）。

- 生成 AI 学习笔记：在资料详情页点「生成 AI 笔记」
- 出练习题：点「出练习题」，可以在线做题并自动判分
- AI 问答：左侧菜单「AI 问答」，会先在你的资料里检索，再让模型作答并标出来源
- **深度思考**：AI 问答页勾上「深度思考」，会换用会推理的模型，像老师讲题一样分步推导，
  回答下面还有一个「展开看 AI 的思考过程」，能看到它自己的推理
- 看图识字：扫描版 PDF 和图片点「AI 识别」，模型能直接读出图里的文字和公式
- 总结打印版：点「总结打印版」会生成一份带 AI 笔记和练习题的排版稿，页面上有
  「打印 / 存为 PDF」按钮，也可以点「下载 Markdown」存成 `.md` 文件

注意：用你本机代理的 AI 只在**你这台电脑开着服务、并且 CC Switch 在运行时**才可用；
别人用自己的密钥时不受这条限制。
换别的模型或云端服务，见「AI 接入设置」。

## 四、资料里的网页 / 动画文件

如果你的资料里有 `.html` 文件（比如物理模型演示），它们在分类页里会显示为「网页」类型，
打开资料详情会**直接在网页里运行**，不用另外打开浏览器找文件。

这些页面跑在沙箱里（没有 `allow-same-origin`），所以它读不到你的账号信息，是安全的。
同一目录下的图片、CSS 等相对路径文件也能正常加载。

## 五、模型动画（站内自带 + AI 自建）

顶部菜单「模型动画」里有 33 个本地绘制的数理化模型，按分类分成三组：

- **数学**：单位圆与正弦函数、二次函数、圆锥曲线统一定义、导数的几何意义、向量平行四边形法则、正态分布、y=A·sin(ωx+φ) 图象变换、频率稳定于概率、正方体旋转与体对角线、等差数列与求和（共 10 个）
- **物理**：平抛、斜抛、匀速圆周运动与向心力、简谐运动、横波传播、等量异种电荷电场线、带电粒子在磁场中、导体棒切割磁感线、动量守恒碰撞、动能定理、多普勒效应、折射与全反射、凸透镜成像、气体状态方程、氢原子能级跃迁（共 15 个）
- **化学**：核外电子分层排布、分子空间构型（VSEPR）、化学平衡移动、中和滴定曲线、原电池、温度与浓度对速率的影响、甲烷正四面体结构、离子键的形成（共 8 个）

每个模型都能拖滑块改参数，支持暂停 / 单步 / 重放 / 变速（0.25× 到 4×），全部本地绘制，断网也能看。
想看清某一瞬间，先点「暂停」，再点「单步」走一帧；拖动滑块改参数时动画会立刻按新参数重画。
变速只是把时间放慢或加快（相当于慢放摄像机），物理规律和数值都不会变。

**自己加一个模型**：页面最下面「自己加一个模型」区块，填一个**类别**（比如
「选修三 电磁感应」）和**模型名称**（比如「带电粒子在磁场中的螺旋运动」），
可以再写补充要求，点「生成动画」。AI 会直接写一个能离线运行的单文件动画保存下来，
生成后出现在下面的「我生成的模型」里，也能在首页「模型动画」中按类别找到。
不想要的可以点「删除」。

要手工再加内置模型，往 `web/models.js` 的 `MODELS` 数组里加一项即可（写一个 `draw` 函数就行）。

## 六、收集资料和知识点（谁都能用）

「收集」页可以把网上的内容存起来，存好会自动加入索引，可以直接搜索、出题、导出：

- **按主题自动收集**：输入一个知识点，系统去网上搜多个来源，抓取正文后让 AI 汇总成一份笔记
- **粘贴网页链接**：把一个网址存成资料
- **粘贴文字**：把你自己整理的笔记存进来

浏览器直接抓不了别的网站（跨域限制），所以「抓正文」会按下面的顺序**依次换通道**，
哪个能用用哪个（页面上也会写明白）：

1. **你电脑上的服务器**：可选增强，最稳。公网版要先去「连接服务器」填地址和连接码（见第十八节）
2. **第三方免费抓取代理**：免费，但经常挂或限流；对方会看到被抓取的网址和正文
3. **你自己的 AI 联网搜索**：花**你自己的额度**，几分钱一次

三个通道都不可用时，会直接告诉你「已尝试 N 个通道都不可用」，不会假装成功。
有些网站（百科、知乎、CSDN 等）不允许抓取正文，这时会自动降级成「搜索摘要」并标注说明。

**联网搜索支持哪些模型**（跟 AI 问答用同一个密钥）：

| 服务 | 联网搜索 | 说明 |
| --- | --- | --- |
| 智谱开放平台 | ✅ | 实测可用；来源列表取自返回里的 `web_search` 字段 |
| 阿里云百炼 | ✅ | 支持联网搜索 |
| DeepSeek | ❌ | 不支持；会自动降级成「自己粘贴知识点」或「上传文件」，其它 AI 功能不受影响 |

**收集来的东西存到哪儿：**

| 谁在用 | 存在哪 | 花谁的钱 |
| --- | --- | --- |
| 管理员（你自己） | 本机资料库 `data\uploads\` | 你的 |
| 普通账号（在局域网网站上用） | 他自己的浏览器 | 他自己的密钥 |
| 公网单文件版（发给别人的文件） | 他自己浏览器 | 他自己的密钥 |

## 七、导出给别人 / 分享这个网站

在「导出」页勾选资料（也可以不勾），然后选模式：

- **单文件 HTML**：图片和小 PDF 会内联进一个 `.html` 文件，微信直接发，对方双击就能看。
  视频和超过 8 MB 的大文件放不进去。
- **打包 zip**：把 HTML + 图片 + 视频 + 原文档一起打成一个压缩包，对方解压后双击
  `index.html`，视频也能播、原文件也在。适合资料比较大的时候（上限 3 GB）。
- **AI 总结打印版**：带 AI 笔记和练习题的排版稿，可打印或存成 PDF。
- **分享版网站**：导出的是**这个学习网站本身**——界面 + 33 个模型动画，再把你勾选的资料
  一起打包成一个单文件 `.html`。里面**没有账号、没有笔记、没有收藏、没有别人的资料**，
  发给别人不会泄露你的私人内容。上传资料时没勾选的东西也不会进去。

搜索结果是**按资料去重**的：同一份资料里命中很多次，也只显示一条（会标注「这份资料里还有 N 处」），
不会刷屏。

## 八、索引进度（只有管理员）

进「索引进度」页可以看到后台处理情况：

- 第一级：把 PDF/docx/pptx/xlsx 里的文字抽出来（快，几分钟到几十分钟）
- 第二级：用 AI 识别扫描件和图片（慢，几百页的扫描版 PDF 要跑很久）

关掉网页也会继续在后台跑，中途关机下次启动会自动接着做。
抽完文字的资料马上就能被搜索到，不用等第二级。

页面底部还有「AI 通道」一块：可以点「检测模型是否可用」，看看当前 AI 接口通不通。
管理员在这块能直接点到管理端去改 AI 设置。

## 九、管理端（管理员专用）

浏览器打开 `http://127.0.0.1:8787/admin`，或者点用户端顶栏的「管理端」。
普通账号会被自动弹回用户端，打不开。

管理端有五个标签页：

- **概览**：账号总数、管理员数、已停用数、违规标记数，以及需要留意的账号
- **账号管理**：每个账号的上传数、笔记数、收藏数、做题数、登录次数、失败次数、越权次数、
  AI 调用次数、违规标记数；可以**停用 / 启用**、**重置密码**、**删除账号**
  （删除会连带删掉他自己的上传、笔记、收藏、做题记录）
- **违规检查**：系统自动盯住下面几类行为
  - 30 分钟内登录失败 ≥ 5 次 —— 疑似在试别人的密码（危险）
  - 1 小时内访问别人的私密资料 ≥ 5 次 —— 疑似越权翻别人的东西（危险）
  - 10 分钟内上传 ≥ 30 个文件 —— 疑似批量灌资料（警告）
  - 1 小时内调用 AI ≥ 200 次 —— 疑似脚本刷接口（警告）
  - 上传 exe / bat / ps1 / vbs / js 等可执行或脚本文件 —— 直接标危险
- **操作日志**：谁在什么时候做了什么（注册、登录、登录失败、上传、导出、AI 提问、越权、
  管理操作……），可以按账号 / 级别 / 动作筛选
- **系统设置**：注册方式（需要邀请码 / 开放注册、一键换邀请码、显示局域网网址）、
  AI 接入、公网版借用本机抓取（开关 + 连接码）、数据存放位置、发布公网版（见下面几节）

规则只是提示，是否真的有问题由你判断。停用账号会立刻把它踢下线，并且不能再登录。

## 十、AI 接入设置（管理员）

管理端 →「系统设置」→「AI 接入」。

默认指向**本机代理**（`http://127.0.0.1:15721/v1`，免密钥），只要 CC Switch 开着就能用。
想换成真的云端大模型，从「服务商预设」里挑一个，会自动填好地址和模型名：

| 预设 | 接口地址 | 文字模型 | 看图模型 |
| --- | --- | --- | --- |
| 本机代理（免密钥，推荐） | `http://127.0.0.1:15721/v1` | `deepseek-v4-pro` | `deepseek-flash` |
| DeepSeek 官方 | `https://api.deepseek.com/v1` | `deepseek-chat` | `deepseek-chat` |
| 硅基流动 | `https://api.siliconflow.cn/v1` | `deepseek-ai/DeepSeek-V3` | `Qwen/Qwen2.5-VL-72B-Instruct` |
| 阿里云百炼（DashScope） | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` | `qwen-vl-max` |
| 智谱开放平台 | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-plus` | `glm-4v-plus` |

填完密钥点「保存」（保存后立刻生效），再点「测试连接」看通不通。
「恢复默认」会退回本机代理。任何 OpenAI 兼容的接口都可以手动填地址使用。

两个模型各管一段：

- **文字模型**：AI 摘要、出练习题、深度思考、生成模型动画
- **看图模型**：扫描件 / 图片识别，以及普通模式的 AI 问答

密钥只存在本机 `storage.json` 里，用户端页面永远读不到，接口返回里也不会带出来。

## 十一、数据存放位置（管理员）

管理端 →「系统设置」→「数据存放位置」。

数据库、上传的资料、缩略图、导出成品都放在一个数据文件夹里。默认是
`D:\学习网页\data`。想挪到空间更大的硬盘：

1. 点「选择文件夹…」挑一个位置（也可以直接填路径）
2. 勾上「把现有数据复制到新目录」（原文件不会删）
3. 点「保存」
4. **重启服务才生效**：先双击 `停止.bat`，再双击 `启动.bat`

默认位置和自定义位置之间来回切都可以，换回来重新选一次默认目录即可。

## 十二、防火墙（手机访问不了时）

以管理员身份打开「Windows 安全中心」→「防火墙和网络保护」→「高级设置」→
「入站规则」→「新建规则」→「端口」→ TCP `8787` → 允许连接 → 命名保存。

## 二十三、手机访问与用自己域名上线

### 23.1 现在手机怎么用（两种方式）

| 场景 | 怎么做 | 体验 |
| --- | --- | --- |
| 手机和电脑在**同一个 Wi-Fi** | 手机浏览器打开 `http://192.168.1.10:8787` | 能登录、能看、能搜、能上传到浏览器本地。但地址栏会显示「不安全」（明文 http），而且手机上**不能**用「选择文件夹」、装不了 PWA |
| 手机**不在同一 Wi-Fi**，或者想要正常的锁 | 电脑上双击 **`隧道.cmd`** | 得到一个 `https://xxx.trycloudflare.com` 地址，**可信证书、没有任何警告**，手机扫弹出的二维码就能开。别人在外地用流量也能打开 |

隧道的三条命令：
```
隧道.cmd              # 启动，自动等它就绪，并弹出手机扫码图片
停止隧道.cmd          # 关掉隧道（电脑上的网站照常运行）
.venv\Scripts\python.exe tools\tunnel.py status   # 看网址 / 看还在不在跑
```

要注意：这种免费临时隧道**每次启动地址都会变**（机器关机就失效），适合"今天给别人看一下"。想要一个固定网址，见 23.2。

### 23.2 为什么不打开自签 HTTPS

自签 HTTPS 能解决"局域网选文件夹"，但会带来你说的那三个问题：每台设备点一次「继续访问」、网址从 http 变 https（旧链接打不开）、改完要重启、825 天还会过期。所以**用隧道代替它**：本机网站一个字都不用改，电脑上照旧 `http://127.0.0.1:8787`。

### 23.3 用自己域名上线（三条路，按推荐排序）

**路 1：Cloudflare Tunnel + 自己的域名（推荐）**
优点：不需要公网 IP、不需要在路由器上开端口、不需要备案，证书自动签发和轮换，网址固定。
前提：域名托管在 Cloudflare（把域名的 NS 换成 Cloudflare 给的两个地址即可）。
```
tools\cloudflared.exe tunnel login                                  # 弹出浏览器，登录并授权一次
tools\cloudflared.exe tunnel create study-web                       # 建一条命名隧道
tools\cloudflared.exe tunnel route dns study-web study.你的域名.com  # 把域名指到隧道
tools\cloudflared.exe tunnel run --url http://127.0.0.1:8787 study-web
```
之后打开 `https://study.你的域名.com` 就是正式网站，锁是绿的。要让隧道跟着电脑开机自启，把
`tunnel run` 那条命令注册成计划任务即可（需要的话我可以做）。
想先看前置条件够不够：`.venv\Scripts\python.exe tools\tunnel.py check`

**路 2：自己的云服务器 / VPS + Caddy（自动 Let's Encrypt）**
优点：完全自主。前提：有公网 IP、80 和 443 能通；国内服务器需要域名**备案**。
把网站放到服务器上（或从家里反代过去），Caddy 两行配置就自动申请并续期可信证书。

**路 3：家里宽带 + 端口转发 + 域名**
最省钱，但国内家用宽带通常封了入站的 80 / 443 端口，且需要备案，成功率和体验都不如前两条。

### 23.4 放到公网必须知道的安全事项

- 公开地址意味着**任何人都能打开登录页**；只要 `注册方式` 保持「需要邀请码」，陌生人就注册不了（邀请码别发到大群里）。
- 登录有 15 分钟内失败 5 次锁 10 分钟的限速，并记进操作日志。
- 资料默认**只有本人可见**，公开地址上别人依然看不到你的全部资料（已实测）。
- 管理端的「共用 AI」保持**关闭**，否则拿到账号的人会消耗你的 AI 额度。
- 不用隧道时随手 `停止隧道.cmd`；长期不用就删掉 `tools\cloudflared.exe`。

## 管理端新增「数据备份」（数据库快照 + 资料清单）

**能做什么**
- 管理端标签栏多了一项「数据备份」（在「操作日志」和「系统设置」之间，还是只有管理员能进）。页面直接显示：数据库多大、库里有几条资料、本机上传目录有几个文件多大、上次备份是什么时候、这份数据目录还剩多少磁盘。
- 两个按钮：
  - **下载数据库快照**：把 `study.db` 整个打包成一个 `.db` 文件下载下来（账号、笔记、收藏、做题记录、资料索引都在这一个文件里）。
  - **下载资料清单**：下载一个 JSON，里面是站点设置、各表条数、按分类统计的文件数和体积、上传目录的逐文件明细。
- 清单里**没有任何密钥**，只有条目和体积。

**怎么做的 / 为什么这么做**
- 快照用的是 SQLite 自己的 `VACUUM INTO`：这是**一条 SQL 在数据库内部完成的一致性拷贝**，WAL 模式下也不会读到写了一半的数据；顺带把碎片整理掉，**不用停服务、不用锁库**。

## 登录页淡入 + 登录成功滑入 + 「连不上服务器」说人话（这一轮）

**两段动画**
- 登录页出现时整体淡入：`opacity 0 → 1`，**300ms**，`ease-out`。实现是 `.overlay.login-page` 上的 `loginFade` 关键帧。
- 登录成功后，首屏内容从**下方 20px** 滑到原位，同时 `opacity 0 → 1`，同样 300ms `ease-out`。实现是 `.page-enter` 上的 `pageIn` 关键帧，由 `app.js` 的 `playEnter()` 在登录后的首屏加类。

## 「选了文件夹还说没选中」的真原因：只申请读权限 + 不再把任何 abort 都说成“你取消了”（2026-10-03 修）

**现象**：点「选择文件夹」、也真的在弹窗里选了文件夹，页面还是弹「没有选中文件夹」，并且停在“还没有选文件夹”那张卡片上；换浏览器、重试都一样。

**根因（三条，前两条是这一轮新查出来的）**
1. `pick()` 要的是 `mode: 'readwrite'`。**写入权限会让浏览器在选完文件夹之后再弹一个“允许修改文件”的小确认框**；那个框很容易被忽略、点掉或者没显示在前面，用户看到的结果就是“我明明选了文件夹，它却说没选中”。而“能不能写”根本不影响扫描、搜索、AI 问答——这些都是只读的。
2. `web/app.js` 的 `folderToast()` 把**所有带 `cancelled` 标记的错误**统一换成一句写死的「没有选中文件夹（弹窗被取消/关掉了）」。也就是说：不管真实原因是什么（窗口压根没弹出来、被浏览器拦了、权限被拒绝），用户看到的永远是“你取消了”——上一轮我们就是被这句话带偏的。
3. 上一轮保留的“取消”判定只按 `AbortError` 走：**几百毫秒内就 abort**（内置浏览器、被管控的浏览器根本弹不出选文件夹窗口）和**用户真的点了取消**（弹窗开了一会儿才关）被当成同一件事。

### 五、接手后第二轮：`启动.bat` / `隧道.cmd`「闪退」的真根因 + HTTPS 联动（2026-10-04 晚）

用户反馈「双击 `启动.bat`、`隧道.cmd` 窗口一闪就没了」，并给了 24 秒录屏（我抽帧看过：全程在文件资源管理器里点这两个文件，**没有任何 cmd 窗口出现过**）。

**根因一：五个 .bat/.cmd 全是 LF 行尾，而 cmd.exe 需要 CRLF**
- 实测证据：`启动.bat` 里 `CRLF=0 / LF-only=19`；直接跑它会报一串「命令不认识」，而且**每行开头被啃掉几个字节**
  （`python.exe` → `ython.exe`、`echo` → `cho`、`echo 要停止服务，双击「停止.bat」。` → `'t」'`、`'击「停止.bat」。'`）。
- 关键对照：把内容一字不改、**只把行尾换成 CRLF** 的副本跑一次 → **一行报错都没有**，而且服务真的起来了。
- 这不是搬目录造成的：新旧两个目录的 `启动.bat` **SHA256 完全相同**，属于一直存在、只是以前没被双击触发的老 bug。
- 修法：`启动.bat`、`停止.bat`、`首次安装.bat`、`隧道.cmd`、`停止隧道.cmd` 全部规范成 CRLF（内容与编码不变）。

**根因二（连带发现）：开了自签 HTTPS 之后，隧道必然是 502**
- 现场：`storage.json` 在 **15:04:58** 被改成 `tls.enabled = true`（用户当时在管理端点出来的），于是 8787 变成 TLS 代理、
  真正的 HTTP 后端退到 8788；而 `tools/tunnel.py` 仍然让 cloudflared 连 `http://127.0.0.1:8787` —— 对 TLS 端口说 http 会被直接断开。
- 修法：`tools/tunnel.py` 把两个端口分开 —— `PORT` 是给人看的网址端口，**`SITE_PORT` 是隧道要连的纯 http 端口**
  （开了 HTTPS 就用 `tls.http_port`），`_site_ok()` 的探针也改用它。
- 另一个连带问题：开了 HTTPS 后 `启动.bat` 还去开 `http://`。因此新增 `tools/site_url.py`，
  `启动.bat` 先问它拿网址，窗口里也会打印「网址：…」；拿不到就回落到 `http://`。

**顺手加的兜底**
- `启动.bat`：等 4 秒后先检查 8787 有没有真的在监听，**没起来就不打开浏览器、打印原因并停住**
  （以前它会默默关掉、什么都不说 —— 正是「闪退」的观感来源）。
- `tunnel.py`：预热 60 秒仍连不上时，除了原有的“稍后刷新”，再提示本机 DNS 负缓存这件事和 `ipconfig /flushdns`
  （这次实测就撞上了：新域名在本机 `No such host is known`，`ipconfig /flushdns` 立刻恢复，而公共 DNS 一直能解析）。

**这一轮的真实验收（都是实跑）**
- 解析：`启动.bat` 输出里 **0 个 not recognized**（改前有 4 个）。
- **一个教训（值得记下来）**：第一次测出「0 个 not recognized」时**服务没起来** → 新加的兜底分支先 `exit /b 1`，
  **后面几行根本没被执行**，于是漏掉了我自己引入的两个 bug。改成「先把服务起起来、再跑完整脚本」后暴露并修掉：
  ① `echo 网址：%SITE%` 那行漏了 `echo`，网址被当成命令执行；
  ② 取网址原本用 `for /f` + 反引号执行 `"…python.exe" …site_url.py`，命令**以引号开头**会触发 `cmd /c` 的引号剥离规则，
  报「文件名、目录名或卷标语法不正确」，于是 SITE 取不到、只打印了默认的 http。
  改成「让 python 把网址写进 `data\site_url.txt`，再用 `set /p` 读」。修完后实测 `0 个解析错误` + `网址：https://127.0.0.1:8787`（正确识别 HTTPS 开关）。
- **行尾防复发**：新增 `.gitattributes`（`*.bat` / `*.cmd` → `eol=crlf`）并执行 `git add --renormalize .`：
  索引里改存 LF、检出时给回 CRLF。**实测走完整圈**：删掉工作区文件 → `git checkout --` 重新检出 →
  `CRLF=39 / 单独LF=0 / 双CR=0 / 大小与原来一致`，再跑一次仍然 **0 个解析错误**、正确打开 https 网址。
- 双击路径：新开控制台跑 `启动.bat` → 8787（TLS）与 8788（HTTP 后端）都在监听，`https://127.0.0.1:8787/api/register/info` **HTTP 200**。
- 隧道端到端：`隧道.cmd` / `tunnel.py start` 拿到 `https://countries-captured-fleece-genes.trycloudflare.com`，
  cloudflared 日志有 `Registered tunnel connection`，公网访问 `/api/register/info`、`/`、`/static/app.js` **全部 HTTP 200**
  （若 `SITE_PORT` 没修，这里必然是 502）。
- `tunnel.py status`：`运行中，PID 19852 / 本机网站：在跑`。
- `使用说明.md` 补了「隧道网址在哪看」（三个地方 + 别用残留旧网址 + DNS 缓存）与 4 条新常见问题。

## 本仓库的实际部署（GitHub Pages + 自定义域名）

- **站点内容**：`docs/index.html` —— 由「管理端 → 发布公网版」生成，`core/webbuild.py` 每次重建都会自动同步这一份
- **Pages 设置**：仓库 Settings → Pages → Source 选 `Deploy from a branch` → Branch `main` + `/docs`
- **自定义域名**：`study-web.com`，已经写在 `docs/CNAME` 里（GitHub 认这个文件）
- **域名托管在 Cloudflare 时，DNS 需要这几条**：

  | 类型 | 名称 | 内容 | 代理状态 |
  | --- | --- | --- | --- |
  | A | `@` | `185.199.108.153` | **先关掉**（灰云 / DNS only） |
  | A | `@` | `185.199.109.153` | 同上 |
  | A | `@` | `185.199.110.153` | 同上 |
  | A | `@` | `185.199.111.153` | 同上 |
  | CNAME | `www` | `yunyunlyk.github.io` | 同上 |

- 等 GitHub 把证书签发好、Pages 里能勾上 **Enforce HTTPS** 之后，再考虑把 Cloudflare 代理打开（橙云）；
  那时 SSL/TLS 模式必须选 **Full (strict)**，否则会重定向循环。
- 站点只放**零资料的离线单文件版**；换分享码之后要重新生成一次公网版并提交 `docs/index.html`，否则线上还是旧门禁。
